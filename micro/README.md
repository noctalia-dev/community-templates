# Micro - Noctalia Community Template
---
This creates a noctalia colorscheme in `$XDG_CONFIG_HOME/micro/colorschemes`. To apply, do either of the following:
- In micro itself, press `ctrl+E` to bring up the command prompt, then enter `set colorscheme noctalia`.
- In micro's settings.json, located in `$XDG_CONFIG_HOME/micro`, add `"colorscheme": "noctalia"`.
