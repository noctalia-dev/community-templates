# Zapfast

Themes [Zapfast](https://github.com/crmne/zapfast) with the active Noctalia palette.

## Setup

1. Launch Zapfast once, then enable this template in Noctalia.
2. In Zapfast, select `noctalia.json` in the theme settings.

Noctalia regenerates the theme when the palette changes. The post-hook attempts to reload Zapfast's themes; if Zapfast is closed, the generated theme will be available the next time it starts.

## Output path

- Native: `$XDG_CONFIG_HOME/zapfast/themes/noctalia.json`
