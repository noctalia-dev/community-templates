# lxqt-config-appearance

**WARNING**: This template modifies files located in `~/.config/lxqt/`

This template creates a color palette for `lxqt-config-appearance`, applies colors to the `[Palette]` section of `~/.config/lxqt/lxqt.conf`

## Notes
 - You might need to restart your session the first time, but after that, it should always work.
 - KDE manages to apply the theme to applications like pcmanfm-qt, but fails to apply it to `xdg-desktop-portal-lxqt`; therefore...
What does this fix? `xdg-desktop-portal-lxqt` now follows the Noctalia color scheme!
