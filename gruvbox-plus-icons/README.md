# Gruvbox Plus Icons — Noctalia Community Template

Recolors the folder icons of [Gruvbox Plus](https://github.com/SylEleuth/gruvbox-plus-icon-pack) with the Noctalia theme's primary color.

Gruvbox Plus installed via your package manager, or placed in your icons directory (`~/.local/share/icons` or `~/.icons`), is currently required.
