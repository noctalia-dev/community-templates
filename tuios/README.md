# TUIOS

Themes [TUIOS](https://github.com/Crmne/tuios) with the active Noctalia palette.

## Setup

1. Launch TUIOS to create its configuration directory.
2. Enable the TUIOS template in Noctalia.
3. Select the `noctalia` theme in TUIOS.

## Output path

- Native: `$XDG_CONFIG_HOME/tuios/themes/noctalia.json`
